How should the story be written?

Put the speaker's name at the start of each line, followed by a colon: **Mira:** Hello there. Bold is recommended, but Mira: Hello there. also works once a name appears at least twice (or is written in ALL CAPS). Anything without a speaker is read by the Narrator. # headings are read by the Narrator too. Add a note in brackets, like **Tobb (quietly):**; it is removed from the spoken text.

Dramatis Personae

Pronunciation fixes

One per line, written as word=how it should sound. Whole words only, not case sensitive. Only the spoken sound changes; the text on screen stays the same.
